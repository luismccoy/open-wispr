# Assets Directory

This directory contains app icons and other assets for Ollie.

## Required Icons

- `icon.png` - Main app icon (1024x1024)
- `icon.icns` - macOS icon
- `icon.ico` - Windows icon
- `iconTemplate@3x.png` - macOS menu bar icon (template image)
- `dmg-background.png` - macOS DMG installer background
